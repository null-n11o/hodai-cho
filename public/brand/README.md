# タベホー ブランド画像

採用済みの「お皿と箸で『タ』を表現する」ロゴを、サイト内で一貫して使うための画像です。

- `tabeho-logo-header.png`（2172 × 724）: 黒背景の共通ヘッダー向け横組みロゴ。`SiteHeader` から `/brand/tabeho-logo-header.png` として参照し、`mix-blend-mode: lighten` で黒をヘッダーの `#171512` になじませます。
- `tabeho-symbol.png`（1254 × 1254）: 生成り背景のブラウザ向けシンボル。`index.html` から `/brand/tabeho-symbol.png` として参照します。

ヘッダー画像は 3:1 の縦横比を維持し、画像内の余白を含めてデスクトップでは CSS 幅 240px、モバイルでは 190px で表示します。
