# 放題帖 コミュニティ問い合わせ・修正依頼

- 日付: 2026-09-08
- 状態: 実装済み

## 目的

掲載内容の誤りや、まだ載っていない「ご飯だけおかわり自由」の店を、利用者が運営へ知らせられるページを追加する。静的SPAのまま運用できるよう、投稿内容はGitHub Issuesの新規投稿画面へ引き渡す。

## 方針

- 日本語・英語の両方に `/contact` と `/en/contact` を用意する。
- ヘッダー、モバイル下部ナビ、検索画面フッターからページへ到達できる。
- 依頼種別、店舗名、変更内容、根拠URL、訪問時期、返信先を入力できる。
- 送信時にGitHub Issuesの下書きURLを生成し、新しいタブで開く。静的サイト側に個人情報や投稿内容を保存しない。
- 既存掲載の修正・店舗追加・閉店/提供終了・その他を受け付ける。
- 投稿は即時掲載ではなく、運営が公式情報や訪問情報を確認してからカタログへ反映する。
- 公式ページ、メニュー写真、訪問日、価格・制限時間など、確認しやすい情報を案内する。
- デザインはコンテンツ面のライトベース「食卓の新聞」、ヘッダーとモバイルナビのダークなブランドシェル、Noto Sans JP、日英対応、44pxタップ面、共通免責に従う。

## 受け入れ条件

- `/contact` と `/en/contact` でフォームと参加方法が表示される。
- 必須項目が未入力なら投稿先を開かず、ブラウザ標準バリデーションが働く。
- 入力内容からGitHub Issuesのタイトル・本文が組み立てられ、新規投稿画面へ遷移する。
- 投稿後は「下書きを開いた」状態を表示し、同じページから再送できる。
- 日本語・英語の言語切替URLが対応する。
- ルート・店・エリア・問い合わせの日英ページをSSGし、sitemapに含める。
- 既存テストと追加したページテスト、型チェック、ビルドが通る。
