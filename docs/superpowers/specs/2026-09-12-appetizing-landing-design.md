# 食欲を誘うLP

2026-09-12、ユーザー承認済み。

- 対象は `/` と `/en/` の独立したLP。暖色・Noto Sans JP・ダークシェルと既存レスポンシブ幅を維持。
- 見出しは「お腹いっぱい、今日は何食べる？」。焼肉・寿司・スイーツの既存料理静物を組み合わせ、ジャンルイメージと明記する。
- 「お肉をがっつり」「お寿司を好きなだけ」「甘いものは別腹」の画像付きボタンでジャンルを単一選択し、`/search/?genre=…`（英語は `/en/search/?genre=…`）へ進む。URLのジャンルは既知値のみ受け付け、未知値は無視する。
- 「食べ放題を探す」から検索サービスへ進める。スマホは1列で、ヒーローの高さを抑える。
- 初回登場は400ms以内の軽いポップ、hover/focus/activeは150–300ms。transformとopacityのみを動かす。繰り返しの自動アニメーションなし。reduce motionではアニメーション・トランジションを無効化。
- UIは日英対応。44px以上の操作面・可視フォーカス・既存検索/保存/予約/免責を維持。

検証: 気分ボタンの条件反映・切り替え・リセット・英語対応をテスト。全テスト、lint、本番ビルド。日英のPC/スマホで画像、はみ出し、操作、reduce motionを確認。

## 実装・検証結果

- 既存料理PNGからWebP派生素材を作成。焼肉800px、寿司/スイーツ480px、品質80。3点合計約116KB。元画像は維持。
- `npm test`: 37ファイル・200テスト成功。新規2テストはボタン未実装時の失敗を確認してから実装。
- `npm run lint`: エラーなし。既存FoodImage/GenreImageのFast Refresh警告2件。
- `npm run build`: 型チェック・本番ビルド成功。
- Chromiumで日英320/390/768/1280pxの横はみ出しなし、画像読込成功、追加操作面44px以上。PC/スマホのスクリーンショットを目視確認。
- 気分選択で結果へフォーカス、「お店を探す」をキーボードで実行してフォームへ移動。reduce motionでアニメーション無効。ブラウザ例外なし。

## 入口ルートの修正

既存LPが含まれるコミット `b6b8b67` を取り込み、トップ `/`・`/en/` はLandingPage、`/search/`・`/en/search/` はSearchPageとする。既存LPのサービス説明・言語ナビ・フッターを維持し、料理ヒーローと気分リンクはLPだけに配置する。検索画面は従来のコンパクトな見出しへ戻す。
前回の検索ページ上部への実装と検証結果は今回の構成で置き換える。トップに検索フォームがないこと、LPから検索への日英遷移、未知ジャンルの扱い、SSGを再検証する。

修正後の検証: 全38ファイル・215テスト成功、lintは既存警告2件のみ、`npm run build:cloudflare` 成功（594 URL）。日英320/390/768/1280pxでトップの検索フォーム不在・横はみ出しなしを確認。PC/スマホを目視し、料理リンクのジャンル引き継ぎ・ロゴからLPへ戻る操作・日英CTAのキーボード遷移・reduce motionを確認した。
