# 少数精鋭チェーンの主要店舗・完全網羅 設計書

- 日付: 2026-09-10
- 状態: 承認済み
- 関連: `docs/superpowers/specs/2026-09-06-hodai-cho-design.md`, `restaurant-catalog-gap-investigation.md`

## 1. 目的と背景

「有楽町で検索したらねぎしがあるはずなのになかった」という事象を受けたカタログ抜け漏れ調査に基づき、店舗数が東京・神奈川で数店舗〜十数店舗規模でありながら、主要ターミナル駅（新宿、池袋、有楽町・銀座、秋葉原、上野、横浜等）で検索漏れの原因となっていた「少数精鋭チェーン」の未登録店舗（計16店舗）を追加する。

本拡張により、以下のブランドが東京・神奈川で**100%全店網羅**（または主要店舗完全カバー）となる：
- **きづなすし**: 2店舗（100%完全網羅）
- **雛鮨 / 祭雛**: 6店舗（100%完全網羅）
- **シズラー**: 12店舗（100%完全網羅）
- **シェーキーズ**: 主要駅（新宿、池袋、吉祥寺、横浜）完全カバー
- **大かまど飯 寅福**: 主要駅直結（青山、横浜、新宿ルミネ、池袋東武）完全カバー
- **モーモーパラダイス**: 主要駅（渋谷、新宿、秋葉原）完全カバー

## 4. 品質基準と検証
- `validateCatalog()` が全店エラーゼロで通過すること。
- 全店の `nameEn` が `Branch` で終わること。
- 全店の駅・エリア・チェーンが `en-names.ts` のテーブルに存在すること。
- SSGビルド（`npm run build:ssg`）で新設エリアおよび全店舗のHTML/sitemapが正常生成されること。
