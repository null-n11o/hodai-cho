# こだわり条件タグ（1人歓迎・幼児無料/子供料金・平日時間無制限）

- 日付: 2026-09-11
- 状態: 設計完了・実装計画へ
- 正本: `docs/superpowers/specs/2026-09-06-hodai-cho-design.md` の要件・UI・カタログ制約を継承する

## 目的

食べ放題特有のリアルな利用シチュエーション（ソロ活、ファミリー、長居滞在）に応えるため、「1人歓迎」「幼児無料・子供料金」「平日時間無制限」の3つのこだわり条件タグを導入し、検索および店舗情報で確認できるようにする。

## 背景と課題

- 一般的なグルメサイトでは「食べ放題」と「1人客歓迎」や「子供料金」の掛け合わせ検索が難しく、公式HPの細かい注意書きを確認する必要がある。
- タベホーの強みである「人手精査された条件帳」として、ユーザーが来店前に最も知りたい3大シチュエーション条件を構造化する。

## 要件定義

### 1. スキーマ拡張 (`Store`)

`src/catalog/schema.ts` に以下の任意真偽値フィールドを追加する：

- `soloFriendly?: boolean;`
  - 1人利用歓迎（カウンター席あり、1名予約・入店受付可、一人鍋/一人焼肉対応、または定食おかわり自由など）。
- `kidsDiscount?: boolean;`
  - 幼児無料、小学生半額、または小学生・キッズ料金設定あり。
- `weekdayUnlimited?: boolean;`
  - 平日（特にランチ等）において時間無制限コースが存在する、または時間無制限設定がある。

※既存の `familyFriendly: boolean;` はデータ互換性のため維持し、`kidsDiscount` は「料金面での子供優遇（無料・割引）」を明示する指標とする。

### 2. 検索条件 (`FilterCond`)

`src/filters/filter.ts` の `FilterCond` にこだわり条件を追加：

- `soloFriendly?: boolean;`
  - `true` の場合、`store.soloFriendly === true` の店舗のみ抽出。
- `kidsDiscount?: boolean;`
  - `true` の場合、`store.kidsDiscount === true` の店舗のみ抽出。
- `weekdayUnlimited?: boolean;`
  - `true` の場合、`store.weekdayUnlimited === true` の店舗のみ抽出。

複数指定された場合は **AND条件**（指定されたすべてのこだわり条件を満たす店舗）で絞り込む。

### 3. UI設計（PLAN Global Constraints 厳守）

- **デザイン方針**:
  - 「食卓の新聞」の世界観を崩さない。
  - ネオン、紫、金、絵文字（❌👶 ❌👤 ❌⏳）、人物写真、外部口コミ星の表示は完全禁止。
  - バッジは落ち着いた枠線スタイル（`border border-line bg-surface text-muted text-xs px-2 py-0.5 rounded`）。
- **検索画面 (`SearchPage` / `FilterSheet`)**:
  - チップ列またはフィルターモーダル内でON/OFF切り替え可能にする。
  - 最小タップ面 44px を確保（チップまたはチェックボックス行）。
- **カード・詳細画面 (`StoreCard` / `DetailPage`)**:
  - 店舗カードのメタ情報行（駅徒歩やジャンルの並び）に、該当するタグのみをスマートに表示。
  - 詳細画面のヘッダー・ハイライト近傍にもバッジを表示。
- **日英対応 (i18n)**:
  - 1人歓迎 / `Solo friendly`
  - 幼児無料・子供料金 / `Kids discount`
  - 平日時間無制限 / `Weekday unlimited`

## カタログデータ精査基準

- プレースホルダ・ダミーデータ禁止。各店舗の公式情報・コース設定に基づき人手精査して設定する。
- 寅福、ねぎし、やよい軒等の定食おかわりチェーンは基本的に `soloFriendly: true`。
- シズラー、シェーキーズ、すたみな太郎、モーモーパラダイス等は公式のキッズ設定・平日制限時間ルールを確認して設定。

## 受け入れ条件

1. `Store` 型に3つのフラグが追加され、カタログバリデーションを通過する。
2. 既存カタログの主要店舗に正確なこだわりタグが付与されている。
3. フィルタロジックで各タグによる絞り込み・複合絞り込みが正確に機能する。
4. 検索画面（日本語・英語）でこだわり条件の選択ができ、該当店舗のみが表示される。
5. 店舗カードおよび店舗詳細に条件バッジが美しく表示される（絵文字なし、食卓の新聞トーン）。
6. 全自動テスト（`npm test`）およびビルド（`npm run build`）がパスする。
